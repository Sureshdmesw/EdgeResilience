# EdgeResilience — 07: Dashboard

## Overview

The EdgeResilience dashboard is a zero-dependency Python HTTP server
that visualizes the V4 demo scenario in a browser.

No external frameworks. No npm. No build step.
Pure Python stdlib + HTML/CSS/JS.

---

## Start the Dashboard

```
python src\dashboard\server.py
```

Then open: **http://127.0.0.1:8765**

---

## What the Dashboard Shows

### Header
- Project name and subtitle
- V4 model name, feature count, observation steps, target

### Simulation Banner
- Explicit SOFTWARE / VIRTUAL-LAB DEMONSTRATION label
- Pipeline flow: risk → resilience → buffering → recovery → sync

### Deployment Status Bar
- CPU Reference: VERIFIED
- ONNX Runtime: VERIFIED
- Snapdragon X Elite: VERIFIED — COMPONENT / WORKLOAD
- Qualcomm QNN / HTP: VERIFIED — COMPONENT / WORKLOAD
- HTP profiling: VERIFIED — VALIDATED WORKLOAD
- Full CPU ↔ Snapdragon numerical equivalence: NOT VERIFIED
- Overall status: CPU_ONNX_VERIFIED_SNAPDRAGON_COMPONENT_WORKLOAD_VERIFIED

### Summary Cards (latest cycle)
- Predictive Risk level (color-coded: green/amber/red)
- Future Degradation value
- Connectivity state (color-coded)
- Evidence record count / Sync status

### Scenario Timeline (all cycles)
Each cycle card shows:
- Cycle ID and label
- Degradation bar (visual, color-coded by risk level)
- Future degradation value
- Risk level
- Connectivity state
- Local inference: YES/NO
- Buffering: YES/NO
- Recovery: YES/NO
- Sync Ready: YES/NO
- Evidence count
- Policy name
- Model name

### Step-Through Demo Button
- "Step Demo" button advances one cycle at a time
- Useful for live presentation: show cycle-001, then cycle-002, then cycle-003
- "Reset" button returns to full view

### Safety Footer
- Physical vehicle test: NO
- External CAN transmission: NO
- Direct actuation: NO
- Production vehicle connection: NO
- Software simulation / virtual laboratory

## API Endpoint

```
GET /api/evidence
```

Returns the full `v4_demo_scenario.json` as JSON.

Useful for programmatic verification:

```python
import urllib.request, json
r = urllib.request.urlopen('http://127.0.0.1:8765/api/evidence')
d = json.loads(r.read())
print(d['model']['name'])           # EdgeResilience_V4_TemporalPredictor
print(d['cycles'][2]['recovery_detected'])  # True
```

## Evidence File

The dashboard reads from:

```
data/evidence/v4_demo_scenario.json
```

This file is generated by:

```
python scripts\generate_v4_demo_evidence.py
```

or by:

```
python demo\run_demo.py
```

Both use the actual V4 checkpoint and produce identical output
(deterministic given fixed checkpoint and input records).
